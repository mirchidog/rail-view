Tutorial

A note on imagery: Rail View is an open source game that uses public data, so the street view imagery is not perfect. As imagery is continually uploaded, station locations will get more precise as time goes on. To learn more or to improve the game's imagery, read the KartaView docs here. Additionally, check out the GitHub project here.

Objective

If you've played GeoGuessr, WorldGuessr, or another similar game, this is almost identical. There are five rounds per game, each showing a street view image from a unique train station across France. Within 60 seconds, try to choose the correct location on the map. The closer an answer is, the progressively more points it receives out of 5000. Keep playing to get a new high score!
